## Selected Projects

**`Σ-Δ ADC`** — 2nd-Order Sigma-Delta Modulator
> Full architecture from loop filter through 1-bit quantizer and DAC feedback. Bitstream analysis via custom Python tooling: SNDR, ENOB, FFT-based signal detection, and noise floor characterization. Verified against behavioral models in MATLAB.

<br/>

**`OTA Design`** — Operational Transconductance Amplifier
> Differential-input OTA optimized for gain, phase margin, and slew rate. Simulated in Cadence Spectre across PVT corners. Designed for use as the core integrating element in sampled-data systems.

<br/>

**`Analog Front-End`** — Signal Conditioning Chain
> Multi-stage signal chain — instrumentation-grade input, programmable gain, anti-alias filter — intended for low-frequency, high-resolution sensing applications.

<br/>

**`FFT Processor`** — FPGA Implementation
> Hardware FFT pipeline on Xilinx ARTY A7. Fixed-point arithmetic, pipelined butterfly stages, verified against MATLAB golden output. Used for real-time spectral analysis of ADC output bitstreams.

<br/>

**`Comparator Block`** — High-Speed Latched Comparator
> Strong-arm latch topology. Characterized for offset, metastability window, and regeneration time. Integrated as the quantizer stage in the Σ-Δ modulator.

## Engineering Philosophy

The analog designer's problem is not just circuit theory — it is the disciplined translation of mathematical ideals into physical constraints. Every node has parasitic. Every transistor has mismatch. Every specification has a tradeoff.

Good analog design is knowing which tradeoff to make, and why.
