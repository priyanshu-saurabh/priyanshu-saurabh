---

### `[ 01 ]`  Current Work

Designing **analog front-end OTA architectures** for next-generation sensing systems. The present focus is on gain-bandwidth optimization, noise floor suppression, and integrating continuous-time analog signal paths with digital back-ends.

Simultaneously developing a custom **Python analysis toolchain** for sigma-delta bitstream characterization — FFT-based SNDR/ENOB extraction, autocorrelated BPM detection, and noise floor visualization.
